# SHS Market Dashboard

Static HTML dashboard for SHS (Saigon-Hanoi Securities) stock market data.

- **Data**: Mock/static — no live API calls
- **Charts**: [Apache ECharts](https://echarts.apache.org/)
- **Stack**: Pure HTML/CSS/JS, zero build step

## Usage

Open `index.html` directly in a browser, or serve via any static host (Vercel, Netlify, GitHub Pages).
